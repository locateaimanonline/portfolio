Use and customize

Three steps to adapt a copy.

  1. 01
    Choose where to use it

    For Codex, place the skill folder in ~/.codex/skills/. For Claude Code, use ~/.claude/skills/. In Claude chat or Desktop, upload the ZIP through Customize → Skills.

  2. 02
    Connect your environment

    For local Jira use, keep the configuration outside either skill folder, supply the API token through JIRA_API_TOKEN, and start with the helper's help operation. Hosted assistants need an authorized Jira connection to reach a private site.

  3. 03
    Fit your practice

    Use each package's README.md to adapt its instructions to your product, issue conventions, publishing system, and style guide.

These packages contain no company connection, private source file, account default, credential, or historical review example. The original installed skills were left unchanged.
