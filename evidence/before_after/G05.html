Configuring Wi-Fi (Android Enterprise)

About this task

Use this task to configure Wi-Fi settings for Android Enterprise devices using a device profile. You can define SSID, security protocols, and proxy settings to enable secure wireless connectivity. Upgrading Zebra devices with LifeGuard OTA

Procedure

  1. From the main menu, navigate to the Profiles view in the SOTI MobiControl web console.
  2. Create or edit an Android Enterprise Work Managed profile. See Create a Profile andEditing a Profile.
  3. On the Configurations tab, select (Add) to add the WiFi configuration from the Connectivity list.
  4. Select (Add) in the WiFi SSID section to specify Wi-Fi setting details.

    5. Network

  5. Enter the Network Name (SSID) for the wireless network.
  6. Enable Set as Active Network to prioritize this network for automatic connection.
    Note: Assigning a new Wi-Fi profile with this option enabled only replaces any existing Wi-Fi profile if the Wi-Fi signal strength is Good or higher.
  7. Enable Disable MAC Randomization if you want devices to use their hardware MAC address.
    Note: Requires Android 13 or later. Assigning a new Wi-Fi profile with this option enabled replaces the existing Wi-Fi configuration.

    8. Security

  8. Select a Security Type for the network.
    • WEP
    • WPA/ WPA 2
    • WPA3 Personal
    • 802.1x Enterprise
    • WPA3 Enterprise
    • WPA3 Enterprise-192 bit
    Note: If you use 802.1x Enterprise, WPA3 Enterprise, WPA3 Enteprise-192 bit, select an authentication protocol and provide further required enterprise authentication details. The WPA3 Enteprise-192 bit protocol only supports TLS. Older or lower-end devices may not support WPA3, limiting universal deployment. Existing network infrastructure and legacy systems that do not support WPA3 may create compatibility issues.

    Available Protocols

    • TLS: Transport Layer Security (TLS) provides end-to-end communications security over networks.
    • LEAP: Lightweight extensible Authentication Protocol (LEAP) provides secure authentication. Not Supported for AMAPI-enrolled devices.
    • EAP-FAST: Extensible Authentication Protocol-Flexible Authentication •Ila Secure Tunneling provides session authentication. Not Supported for AMAPI.
    • TTLS: Tunneled Transport Layer Security provides secure connection tunnel to authenticate the client.
    • PEAP: Protected Extensible Authentication Protocol encapsulates the Extensible Authentication Protocol (EAP) within an encrypted and authenticated Transport Layer Security (TLS) tunnel.

    Required Authentication Details

    9. Proxy

  9. Configure proxy settings as needed.
    • None: Skip proxy settings for the Wi-Fi connection.
    • Automatic: Enter a Proxy Auto-Configuration (PAC) file URL to automatically retrieve proxy settings from the specified location.
    • Manual: Enter proxy settings manually. Specify the proxy server address and (optionally) the port number. In the Exceptions field, optionally list any host exceptions that should connect directly without using the proxy.
      Tip: Separate entries with commas.
  10. Save and assign the profile to your target Android Enterprise devices.

Result

Devices connect to the specified Wi-Fi network with the configured settings once the profile installs.
